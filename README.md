## ✨ 核心亮点：反幻觉三道防线

大模型最危险的错误是「一本正经地编造财务数字」。本项目**不依赖模型自觉**，而是用确定性校验兜底：

| 防线 | 做什么 | 效果 |
|---|---|---|

| **② 数字校验** | 报告里每个数字都跟真实数据交叉核对 | 抓出编造的数字 |
| **③ 逻辑审校** | 检查因果关系、引用覆盖率、三表勾稽 | 抓出逻辑错误 |

实际效果：模型把营收写成 182.30 亿（真实是 152.30 亿），校验器精确抓出并自动纠错。

## 🛡️ 反幻觉详细原理

大模型最危险的错误是「一本正经地编造财务数字」。本项目**不依赖模型自觉**，而是用四道防线兜底：

```
AKShare 真实数据 → 清洗 → 事实库 FactBase（唯一数字来源，输入侧锁定）
                          │
                          ▼
              大模型只能依据「事实包」生成草稿
                          │
                          ▼
   CrossVerifier 抽取草稿中的每个数字声明，逐条与事实库按容差比对
                          │
        ┌─────────────────┴─────────────────┐
        ▼                                   ▼
   一致 supported                    矛盾 mismatch（疑似幻觉）
        │                                   │
        ▼                                   ▼
     输出成稿            回填「正确值纠错清单」→ 模型重写 → 再校验
```

### 四道防线详解

| 防线 | 做什么 | 怎么做 |
|---|---|---|
| **① 输入约束** | 不让模型自由发挥 | 只把清洗后的「事实包」给模型，明确说「只能用这些数据」 |
| **② 数字校验** | 抓出编造的数字 | 报告里每个数字都跟真实数据交叉核对，容差 1% |
| **③ 语义校验** | 抓出无来源的定性判断 | 检查「这个判断有没有事实包支撑」，没有就标记 |
| **④ 逻辑审校** | 抓出逻辑错误 | 三大报表勾稽校验、引用覆盖率检查、多空辩论平衡度 |

### 实际效果

模型把营收写成 182.30 亿（真实是 152.30 亿）、净利增速 15.20%（真实是 9.40%）、毛利率 50%（真实是 42.30%），校验器精确抓出三处矛盾并给出真实值：

```
交叉校验结论：未通过｜共核对 6 处数值：一致 3、矛盾 3、无法核实 0｜疑似幻觉率 50.0%
  [✗] 归母净利润同比增速：文本称 15.20%，应为 9.40%
  [✗] 销售毛利率：文本称 50.00%，应为 42.30%
```

## 🤖 多智能体流水线详解

深度研报（`report` 命令）不是一次性让大模型写完，而是分成 6 个阶段，每个阶段由专门的智能体负责：

```
用户输入研究主题
        │
        ▼
① Planner（规划提纲）
   大模型自动生成研究提纲：核心观点 / 行业背景 / 市场规模 / 产业链 / 竞争格局 / 风险 / 结论
        │
        ▼
② Researcher（检索资料）
   自动生成 10 条检索词，去重后搜索相关资料
        │
        ▼
③ Analyst（逐章分析）
   每章自动提炼要点，标注引用来源 [1, 2, 3...]
        │
        ▼
④ Debate（多空辩论）
   多方 vs 空方对抗分析，双方各 3-5 个论点 + 两轮互相反驳
        │
        ▼
⑤ Writer（撰写报告）
   自动写成完整报告
        │
        ▼
⑥ Reviewer（审校修订）
   自动审校：数字校验 / 引用覆盖率 / 逻辑一致性，有问题就打回重写
        │
        ▼
   输出最终报告
```

**为什么要这么设计？**  
因为一次性让大模型写完整报告会「顾头不顾尾」，数字容易错、逻辑容易乱。分成 6 个阶段，每个阶段只做一件事，质量更高。

## 🔌 接口与集成详解

### MCP Server（Model Context Protocol）

**什么是 MCP？**  
Anthropic 推出的开放协议（类似 AI 界的 USB-C），用于标准化 LLM 与外部工具/数据源的连接。

**怎么用？**

1. 启动 Web 服务：`python main.py serve`
2. 在 Claude Desktop / Cursor 的 `mcp.json` 里配置：
   ```json
   {
     "mcpServers": {
       "research-report-agent": {
         "url": "http://localhost:8000/mcp"
       }
     }
   }
   ```
3. 然后就可以在 Claude / Cursor 里直接调用：
   - `get_stock_brief(symbol="600519")`：公司速览
   - `verify_numbers(text="...")`：数字反幻觉校验
   - `generate_stock_report(topic="低空经济")`：生成完整研报

### FastAPI Web 服务

**API 列表：**

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/brief?symbol=600519` | GET | 公司速览 |
| `/api/report?topic=低空经济` | GET | 深度研报（SSE 实时进度） |
| `/mcp` | POST | MCP 协议入口 |
| `/mcp/tools` | GET | 查看所有 MCP 工具 |

## 💡 最佳实践

### 怎么用效果最好？

1. **配多个数据源**：AKShare + Tushare 一起用，自动交叉验证，数字更准
2. **跑多份报告后看 stats**：跑 5-10 份不同公司的报告，然后用 `python main.py stats` 看看你的模型靠不靠谱
3. **选可信度 A 级的报告**：如果可信度是 B/C/D，建议人工复核关键数据
4. **用 Web 界面**：新手推荐 Web 界面，零命令操作
5. **配每日推送**：配一次之后，每天早上自动收到自选股速览，不用打开任何页面

### 怎么避免幻觉？

1. **选好模型**：不同模型幻觉率不一样，用 `stats` 命令对比哪个模型更靠谱
2. **多看反幻觉总览**：报告结尾有「🛡️ 反幻觉总览」章节，看看可信度等级
3. **多源交叉验证**：选多个数据源，同一个数字不一样就标记出来
4. **关键数据人工复核**：如果要拿报告做投资决策，关键数据（营收/净利润/PE/PB）建议自己再核对一下
