# research agent

#### Description
本项目是面向行业研究的轻量化辅助工具，使用 Python + AKShare 获取A 股上市公司公开数据，结合大模型能力完成数据清洗、信息提炼。针对大模型容易产生幻觉的问题加入交叉校验逻辑，保障输出内容可溯源，辅助完成公告要点提取、行业素材汇总，适用于基础投研信息整理。
